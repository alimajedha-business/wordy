# Kalameh Bazi --- Agent Handoff

This folder contains the product and implementation instructions for the
**کلمه‌بازی** project.

## Files

-   `agent.md` --- instructions and implementation workflow for the
    coding agent.
-   `spec.md` --- complete product requirements, rules, fairness model,
    UX, data model, and acceptance criteria.

## How to use

1.  Copy both files into the root of the project repository.

2.  Give your coding agent this instruction:

    > Read `agent.md` and `spec.md` completely. Inspect the repository,
    > then implement the project in milestones. Treat `spec.md` as the
    > source of truth. Start with a short implementation plan and then
    > implement Milestone 1. Do not skip tests or silently change game
    > rules.

3.  Review each milestone before asking the agent to continue.

## Product direction

Build a React + TypeScript + Vite mobile-first PWA. This allows the game
to run on iPhone through Safari and be added to the Home Screen without
App Store distribution.
