# کلمه‌بازی (Kalameh Bazi)

یک بازی دورهمی تیمی مدرن، سریع و هیجان‌انگیز با یک گوشی هوشمند مشترک، طراحی‌شده به صورت موبایل‌محور (Mobile-First)، تماماً به زبان فارسی (راست‌به‌چپ)، با زمان‌سنج دقیق بدون افت و الگوریتم انتخاب کاملاً عادلانه کلمات.

---

## ویژگی‌های کلیدی

- **طراحی ریسپانسیو و موبایل‌محور (Mobile-First)**: بهینه‌سازی‌شده برای نمایش پرتره در انواع گوشی‌ها، تبلت و دسکتاپ بدون اسکرول افقی.
- **پشتیبانی کامل از Safe Area آیفون**: سازگار با ناچ (Notch)، داینامیک آیلند و Home Indicator با متاتگ `viewport-fit=cover`.
- **اپلیکیشن تحت وب پیشرونده (PWA)**: قابلیت نصب مستقیم به عنوان نرم‌افزار مستقل (Standalone) در صفحه اصلی آیفون و اندروید، همراه با Service Worker جهت پشتیبانی کامل از حالت آفلاین.
- **زمان‌سنج دقیق مبتنی بر ساعت واقعی (Wall-Clock Deadline)**: عدم افت زمان در صورت قفل شدن صفحه یا رفتن مرورگر به پس‌زمینه (Backgrounding).
- **الگوریتم انتخاب عادلانه کلمات (Fair Prompt Planner)**: برابری کامل نوع و سطح سختی کلمات در هر اسلات برای تمام تیم‌ها بدون تکرار کلمه در یک مرحله.
- **پایداری داده‌ها و بازیابی خودکار (Crash / Refresh Recovery)**: ذخیره‌سازی محلی در IndexedDB با پشتیبان LocalStorage جهت بازیابی بازی پس از رفرش ناخواسته یا باز کردن مجدد مرورگر.
- **پوشش ۱۰۰٪ سناریوهای پذیرش**: دارای ۵۸ آزمون خودکار شامل ۱۶ سناریوی پذیرش مشخص‌شده در مستندات.

---

## قوانین مسابقه در یک نگاه

بازی در **۳ مرحله** با روش‌های انتقال مفهوم متفاوت و ضرایب امتیازی صعودی اجرا می‌شود:

| مرحله | شیوه اجرا | مدت نوبت هر تیم | امتیاز هر پاسخ | سطح سختی | محدودیت کلمات |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **مرحله ۱** | توضیح در یک جمله | ۵ دقیقه (۳۰۰ ثانیه) | **+۱** امتیاز | آسان | کلمه و عبارت (ضرب‌المثل ممنوع) |
| **مرحله ۲** | پانتومیم / ادابازی | ۱۲ دقیقه (۷۲۰ ثانیه) | **+۳** امتیاز | متوسط | کلمه، عبارت و ضرب‌المثل |
| **مرحله ۳** | نقاشی | ۲۰ دقیقه (۱۲۰۰ ثانیه) | **+۵** امتیاز | سخت | کلمه، عبارت و ضرب‌المثل |

### قوانین امتیازدهی و خطاها:
- **درست**: افزایش امتیاز طبق ضریب مرحله و رفتن به کلمه بعدی.
- **رد کردن (Skip)**: بدون تغییر امتیاز (۰)؛ با هر بار رد کردن کلمه، **۷ ثانیه از زمان باقی‌مانده نوبت به عنوان جریمه کسر می‌شود** و بلافاصله کلمه بعدی نمایش داده می‌شود.
- **ثبت خطا**: کسر دقیق ۱ امتیاز از تیم متخلف.
- **کف امتیاز صفر (Score Floor)**: امتیاز هرگز کمتر از صفر نمی‌شود. اگر تیمی دارای صفر امتیاز باشد، خطا ثبت می‌شود اما امتیاز در صفر باقی می‌ماند.
- **تساوی‌ها (Ties)**: تیم‌های دارای امتیاز برابر، رتبه کاملاً یکسان دریافت می‌کنند (بدون ابداع روش‌های تصادفی برای شکستن تساوی).

## راه‌اندازی، اجرا و آزمون‌ها

### پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- npm نسخه 9 یا بالاتر

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای سرور توسعه (Local Dev)
```bash
npm run dev
```
سرور به صورت پیش‌فرض روی آدرس `http://localhost:5173` با دسترسی روی تمام کارت‌های شبکه (`0.0.0.0`) اجرا می‌شود تا بتوانید با گوشی تلفن همراه در همان شبکه وای‌فای (Wi-Fi) نیز به آن دسترسی داشته باشید.

### اجرای آزمون‌های خودکار (Vitest)
```bash
npm test
```
تمامی ۵۸ آزمون واحد و یکپارچه‌سازی در ۷ سوئیت اجرا می‌شوند.

### ساخت باندل نهایی (Production Build)
```bash
npm run build
```
کدهای تایپ‌اسکریپت بررسی شده و خروجی فشرده به همراه Service Worker و مانیفست PWA در پوشه `dist/` ایجاد می‌شود.

## راهنمای نصب روی آیفون (iPhone Add to Home Screen)

این برنامه به عنوان یک PWA استاندارد بدون نیاز به نصب از App Store، به صورت یک اپلیکیشن بومی تمام‌صفحه روی آیفون اجرا می‌شود:

1. آدرس سایت (مستقرشده روی HTTPS یا شبکه وای‌فای محلی) را در مرورگر **Safari** باز کنید.
2. روی دکمه **Share** (آیکون مربع با فلش رو به بالا در نوار پایین مرورگر) بزنید.
3. در منوی گزینه‌ها به پایین رفته و گزینه **Add to Home Screen** (افزودن به صفحه اصلی) را انتخاب کنید.
4. در صورت نمایش گزینه Open as Web App، آن را فعال بگذارید و روی دکمه **Add** در گوشه بالای صفحه بزنید.
5. اکنون آیکون **کلمه‌بازی** در کنار سایر اپلیکیشن‌های شما قرار گرفته و بدون نوار مرورگر به صورت تمام‌صفحه و با پشتیبانی آفلاین باز می‌شود.

## راهنمای استقرار روی سرورهای آنلاین (Deployment Guide)

### ۱. استقرار روی Vercel / Netlify
- دستور ساخت (Build Command): `npm run build`
- پوشه خروجی (Output Directory): `dist`
- تمام درخواست‌ها به صورت خودکار به `index.html` هدایت می‌شوند.

### ۲. استقرار با Nginx / سرور اختصاصی
نمونه کانفیگ Nginx با پشتیبانی از کش PWA و روتینگ SPA:
```nginx
server {
    listen 443 ssl http2;
    server_name kalamehbazi.example.com;

    root /var/www/kalameh-bazi/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # کش دارایی‌های تغییرناپذیر
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, no-transform";
    }

    # عدم کش سرویس‌ورکر جهت به‌روزرسانی آنی
    location = /sw.js {
        expires 0;
        add_header Cache-Control "no-cache, no-store, must-revalidate";
    }
}
```
