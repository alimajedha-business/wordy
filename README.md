# کلمه‌بازی (Kalameh Bazi)

یک بازی دورهمی تیمی و سرگرم‌کننده با یک گوشی هوشمند مشترک، طراحی‌شده برای زبان فارسی (راست‌به‌چپ)، با زمان‌سنج دقیق و الگوریتم قرعه‌کشی عادلانه کلمات.

## فناوری‌ها

- **فرانت‌اند**: React 18 + TypeScript + Vite
- **رابط کاربری**: Material UI (MUI) v5 به همراه تم اختصاصی تاریک و بهینه‌سازی‌شده برای موبایل
- **فونت و زبان**: فونت فارسی Vazirmatn، پشتیبانی کامل راست‌به‌چپ (RTL) با Emotion و `stylis-plugin-rtl`
- **اپلیکیشن تحت وب پیشرونده (PWA)**: قابل نصب روی آیفون و اندروید، پشتیبانی از حالت آفلاین و Service Worker
- **آزمون‌ها**: Vitest و React Testing Library

## قوانین بازی در یک نگاه

بازی در **۳ مرحله** با روش‌های مختلف اجرا می‌شود:

1. **مرحله ۱: توضیح در یک جمله**
   - زمان نوبت هر تیم: ۵ دقیقه (۳۰۰ ثانیه)
   - امتیاز هر پاسخ درست: +۱ امتیاز
   - قانون: توضیح مفهوم تنها با یک جمله و بدون ذکر ریشه کلمه. ضرب‌المثل در این مرحله ممنوع است.
2. **مرحله ۲: پانتومیم و ادابازی (Charades)**
   - زمان نوبت هر تیم: ۱۲ دقیقه (۷۲۰ ثانیه)
   - امتیاز هر پاسخ درست: +۳ امتیاز
   - قانون: نمایش مفهوم با حرکات دست و بدن بدون کلام یا نوشتن.
3. **مرحله ۳: نقاشی**
   - زمان نوبت هر تیم: ۲۰ دقیقه (۱۲۰۰ ثانیه)
   - امتیاز هر پاسخ درست: +۵ امتیاز
   - قانون: کشیدن نقاشی روی کاغذ/تخته بدون نوشتن حروف و ارقام.

- **ثبت خطا**: هر خطا ۱ امتیاز از تیم کسر می‌کند (کف امتیاز صفر است و منفی نمی‌شود).
- **رد کردن (Skip)**: امتیازی کم نمی‌کند.

## ساختار پوشه‌بندی پروژه

```
/
├── docs/                 # مستندات و مشخصات پروژه (agent.md, spec.md)
├── public/               # آیکون‌ها و فایل‌های ایستا PWA (favicon, pwa-192, pwa-512)
├── scripts/              # اسکریپت‌های کمکی بیلد و ساخت آیکون
├── src/
│   ├── components/       # کامپوننت‌های مشترک رابط کاربری (AppShell, RulesDialog)
│   ├── features/         # ماژول‌های بخش‌های بازی (setup, game, scoreboard, bank)
│   ├── game/             # لایه منطق دامنه (types, rules, scoring, timer, planner)
│   ├── data/             # بانک بذر کلمات و ضرب‌المثل‌های پالایش‌شده
│   ├── theme/            # تم MUI، فونت Vazirmatn و کش RTL
│   ├── storage/          # لایه ذخیره‌سازی محلی (LocalStorage / IndexedDB)
│   ├── App.tsx           # مدیریت صفحات و کامپوننت ریشه
│   ├── main.tsx          # نقطه ورودی، تم، PWA و پیکربندی RTL
│   └── index.css         # استایل‌های سراسری، متغیرهای Safe Area و ریست
├── tests/                # آزمون‌های خودکار Vitest
├── index.html            # نقطه ورود HTML با تگ‌های PWA و viewport-fit
├── vite.config.ts        # تنظیمات Vite، PWA و Vitest
├── tsconfig.json         # تنظیمات تایپ‌اسکریپت سخت‌گیرانه
└── package.json          # پکیج‌ها و اسکریپت‌ها
```

## راه‌اندازی و توسعه محلی

### پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- npm نسخه 9 یا بالاتر

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای سرور توسعه (Local Dev)
```bash
npm run dev
```
سرور روی آدرس `http://localhost:5173` با دسترسی `0.0.0.0` اجرا می‌شود تا بتوانید با گوشی در همان شبکه وای‌فای نیز به آن دسترسی داشته باشید.

### اجرای آزمون‌ها (Tests)
```bash
npm test
```

### بیلد نهایی و بررسی تایپ‌ها
```bash
npm run build
```

## راهنمای نصب روی آیفون (iPhone Add to Home Screen)

برای استفاده به عنوان اپلیکیشن تمام‌صفحه بدون نوار مرورگر:

1. آدرس سایت (مستقرشده روی HTTPS یا شبکه محلی) را در مرورگر **Safari** باز کنید.
2. روی دکمه **Share** (آیکون مربع با فلش رو به بالا در پایین صفحه) بزنید.
3. در منوی بازشده، گزینه **Add to Home Screen** (افزودن به صفحه اصلی) را انتخاب کنید.
4. در صورت نمایش گزینه Open as Web App، آن را فعال بگذارید و دکمه **Add** را در بالای صفحه بزنید.
5. اکنون آیکون **کلمه‌بازی** به صفحه اصلی آیفون اضافه شده و به صورت اپلیکیشن مستقل باز خواهد شد.
